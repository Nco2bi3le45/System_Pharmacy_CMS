# CMS Pharmacy Inventory System

A smart pharmacy inventory system designed for Central Medical Stores (CMS).

## Features
- Real-time stock tracking
- Low stock alerts
- Expiry monitoring
- WhatsApp alert integration
- Analytics dashboard
- PDF reporting

## Technologies
- Python (Flask)
- PostgreSQL
- Twilio API
- Matplotlib

## Purpose
To improve medicine availability, reduce stockouts, and support healthcare operations.
